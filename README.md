## VS Code extension — Dotenv Scanner

<a href="https://marketplace.visualstudio.com/items?itemName=chief2001.dotenv-scanner&ssr=false#overview">
  <img src="https://img.shields.io/badge/Install-Dotenv_Scanner-007ACC?style=for-the-badge&logo=visualstudiocode&logoColor=white" alt="Install Dotenv Scanner from Visual Studio Marketplace" />
</a>

**Ever referenced an environment variable in code and forgotten to add it to `.env`?** I built **Dotenv Scanner** to catch that problem directly inside VS Code.

- 🔎 **Missing variables:** Flags `process.env.API_URL` or `import.meta.env.API_URL` references that aren't defined in scanned `.env` files.
- 🧹 **Unused variables:** Warns about `.env` entries that aren't referenced by scanned source files.
- 🛠️ **Configurable:** Choose source directories, file extensions, and diagnostic severity.
- ⚡ **Developer-friendly:** See issues in VS Code's **Problems** panel and run scans from the Command Palette.

Works with JavaScript and TypeScript projects (`.js`, `.jsx`, `.ts`, `.tsx`, `.mjs`).

**[→ Explore and install Dotenv Scanner](https://marketplace.visualstudio.com/items?itemName=chief2001.dotenv-scanner&ssr=false#overview)**
